Fitur

Semua yang sering kamu ketik, tinggal sekali klik

Bukan sekadar simpan teks. SematIn menangani variabel, gambar, lampiran, dan pengisian di semua situs yang kamu pakai setiap hari.

Mengunggah gambar…

Sisip gambar

Gambar diunggah otomatis ke Catbox saat disisipkan — sebagai gambar di dalam teks atau sebagai file lampiran. Foto besar dikompresi dulu (ukuran & kualitas bisa diatur). Bisa banyak file sekaligus, progresnya terlihat langsung di tempatnya. Gambar dari clipboard juga bisa ditempel langsung di editor.

Dukung di Trakteer

Dukung pengembangan SematIn lewat Trakteer — tombol di footer popup membuka form tip langsung di dalam ekstensi, tanpa buka tab baru.

Bagikan lewat link

Bagikan satu template atau banyak sekaligus lewat link — penerima tinggal impor dari URL, tanpa perlu kirim file.

Bandingkan versi

Pilih dua versi template dari riwayat dan lihat perbedaannya baris per baris — tambahan berwarna hijau, hapusan berwarna merah.

Klik-kanan, langsung terisi

Klik kanan di kolom teks apa pun, pilih template dari menu SematIn, dan teks langsung terisi. Kalau ada variabel, form isian terbuka dulu.

Import dari URL

Tempel link file JSON template di dialog Backup — dari GitHub raw, gist, atau Catbox — dan template langsung masuk tanpa perlu mengunduh dulu.

Pustaka gambar

Semua gambar yang pernah diunggah dari template kamu terkumpul di satu tempat. Unggah langsung ke pustaka, lalu pakai ulang sebagai gambar atau file, tanpa upload lagi.

Variabel otomatis

{{nama}}, tanggal hari ini dengan format bebas, sampai nomor urut otomatis — semuanya terisi sendiri setiap kali template dipakai.

Template include

Pakai template di dalam template lain dengan {{include:Nama}} — sampai 10 tingkat, siklus terdeteksi otomatis. Variabel dan gambar dari template yang di-include ikut terisi.

Arsip, cari, & ekspor

Arsipkan template lama, cari dalam sekejap, dan ekspor-impor cadangan JSON tanpa kehilangan gambar, arsip, atau hitungan pemakaian.

Susun sesukamu

Seret kartu template untuk mengurutkannya sendiri — di tab All maupun per kategori — dan beri warna pada tiap kategori supaya gampang dibedakan. Tab kategorinya pun bisa diseret untuk diubah urutannya, atau disembunyikan bila sedang tidak dipakai.

Baru di v2.0.7

Editor lengkap

Tulis template dengan tebal, miring, garis bawah, daftar, tabel, garis pemisah, dan perataan — plus warna teks dan highlight. Tabel bisa dinavigasi dengan keyboard: panah pindah sel, Shift+panah atau Shift+klik memilih beberapa sel.

Tambah dari seleksi

Blok teks di halaman web mana pun, klik kanan, pilih Add to SematIn — formatnya ikut tersimpan. Draf editor tetap ada kalau popup tertutup.

Isi di mana saja

Template terisi ke WhatsApp, Threads, Facebook, Instagram, LinkedIn, Gmail, dan Google Docs — formatnya menyesuaikan tiap editor.

Isi massal dari Excel

Impor data .xlsx/.xls ke template — tiap baris mengisi variabel berikutnya, lengkap dengan progres per file dan tanggal yang terformat rapi.

Backup & pulihkan

Ekspor-impor template sebagai JSON, cadangan otomatis terjadwal setiap hari, minggu, atau bulan, dan pulihkan dari backup terakhir. Template yang dihapus masuk Trash dulu selama 30 hari.

Tampilan sesuai selera

Mode gelap atau terang — bisa mengikuti sistem — buka sebagai popup atau di sidebar, dan pilih warna aksen sesukamu: logo header ikut berubah warna. Pengaturan kini bertab, rapi, dan gampang dicari. Ada juga mode daftar ringkas supaya lebih banyak template muat di layar.

Cara kerja

Tiga langkah, selesai

  1. 1

    Simpan sekali

    Tulis template di popup SematIn, tambahkan variabel seperti {{nama}}, dan sisipkan gambar kalau perlu.

  2. 2

    Pilih template

    Buka popup dan tekan “Gunakan”, atau klik-kanan di kolom teks dan pilih dari menu SematIn.

  3. 3

    Terisi otomatis

    Teks dan gambar menempel di kolom tujuan — WhatsApp, Threads, Facebook, atau situs apa pun. Variabel sudah terisi.

FAQ

Yang sering ditanyakan

Apakah SematIn gratis?

Ya, gratis. Tidak ada akun, tidak ada langganan, dan tidak ada batas jumlah template. Unduh dari GitHub Releases dan langsung pakai.

Bagaimana cara memasangnya?

Unduh file zip dari SematIn-Releases, ekstrak, lalu buka chrome://extensions, aktifkan Developer mode, dan pilih “Load unpacked” ke folder hasil ekstrak.

Apakah data saya aman?

Template tersimpan lokal di browser (chrome.storage.local) dan tidak dikirim ke mana-mana. Gambar hanya diunggah ke Catbox saat kamu menyisipkannya, dan tautannya tersimpan bersama template.

Apakah bisa di Microsoft Edge?

Ya. Edge berbasis Chromium dan mendukung ekstensi Manifest V3 yang sama dengan Chrome, jadi SematIn bisa dipasang dengan cara yang sama (Load unpacked dari edge://extensions).

Apakah bisa dipakai di HP?

Belum. SematIn adalah ekstensi Chrome desktop, jadi dipakai di Chrome atau Edge di komputer.

Di mana saya bisa minta fitur atau lapor bug?

Melalui Issues di repositori GitHub aidilaryanto/SematIn.
